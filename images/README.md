# Sorting Algorithm Visualizer

A web-based application that demonstrates how different sorting algorithms work through interactive visualizations. This project helps users understand the step-by-step execution of sorting algorithms by animating comparisons and swaps in real time.

## Features

* Visualize popular sorting algorithms
* Generate random arrays
* Adjustable array size
* Control sorting speed
* Real-time animation of comparisons and swaps
* Responsive and user-friendly interface

## Sorting Algorithms Implemented

* Bubble Sort
* Insertion Sort

## Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Optional Enhancements

* React.js
* Tailwind CSS

## How It Works

1. Generate a random array.
2. Select a sorting algorithm.
3. Click the "Start Sorting" button.
4. Watch the algorithm sort the array step by step.
5. Compare the behavior and efficiency of different algorithms.

## Time Complexities

| Algorithm      | Best Case  | Average Case | Worst Case |
| -------------- | ---------- | ------------ | ---------- |
| Bubble Sort    | O(n)       | O(n²)        | O(n²)      |
| Insertion Sort | O(n)       | O(n²)        | O(n²)      |

## Installation
Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd sorting-algorithm-visualizer
```

Open `index.html` in your browser or run a local development server.
